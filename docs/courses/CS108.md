# Object-Oriented Programming

面向对象程序设计以 C++ 为主要载体，训练从过程式程序到对象模型的思维转换。课程重点不只是语法，而是对象生命周期、封装、继承、多态、异常、模板和 STL 背后的设计约束。

## 课程主线

1. 类与对象：构造、析构、访问控制和成员函数。
2. 对象交互：组合、继承、虚函数与多态。
3. 资源管理：拷贝构造、赋值运算符、动态内存和 RAII。
4. 泛型程序设计：模板、迭代器、STL 容器与算法。
5. 稳健性：异常处理、智能指针和工程化代码风格。

## 学习建议

OOP 最容易丢分的地方是对象生命周期。复习时建议反复手推构造、拷贝、赋值和析构的调用顺序，再叠加虚函数、异常传播和模板实例化。只要这条线稳住，很多看起来零散的 C++ 题都会变得可推导。
