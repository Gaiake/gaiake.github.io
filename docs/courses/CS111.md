# Social Networks and Security Privacy

社交网络与安全隐私关注人在网络中的连接、传播、身份与隐私风险。它把图分析、网络测量、推荐与隐私保护放在同一个问题域里，适合作为安全、数据挖掘和 AI 社会影响方向的交叉课程。

## 课程主线

1. 社交网络建模：节点、边、社区、中心性与传播路径。
2. 网络数据分析：采集、清洗、统计指标与可视化。
3. 隐私与安全：画像、重识别、信息泄露和防护方法。
4. 实验写作：从任务要求、数据处理到报告结构。

## 学习建议

这类课程要特别注意数据伦理。做实验时不仅要说明指标和结论，也要说明数据来源、匿名化处理、潜在偏差和隐私风险。技术上看，它和图算法、统计分析、推荐系统都有联系。
