# Course Comprehensive Practice I

课程综合实践 I 偏向高性能计算与工程实训，内容从 HPC 基础、向量化优化到 TinyLLM 项目实践。它不像传统理论课那样只看公式，而是要求把性能、硬件特性、实验报告和可复现实验放在一起。

## 课程主线

1. HPC 基础：并行计算、硬件层次、性能指标。
2. 向量化与矩阵计算：理解 AVX、AMX 等指令级优化思路。
3. 实验训练：从 benchmark、profiling 到报告撰写。
4. TinyLLM 项目：把系统优化与模型推理任务联系起来。

## 学习建议

实践课的关键是把实验过程写清楚：硬件环境、基线、优化点、对照实验和性能变化。不要只给最终加速比，最好解释为什么某个优化有效，以及它在哪些输入规模或硬件条件下可能失效。
