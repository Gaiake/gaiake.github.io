# Fundamentals of Data Structures

数据结构基础是计算机专业从“会写程序”走向“会组织程序”的关键课。它讨论的不只是链表、树、图这些结构本身，更重要的是：在不同问题里怎样选择数据组织方式，怎样估计算法代价，怎样把抽象结构落到可测试的 C 代码里。

## 课程主线

1. 复杂度分析：从循环、递归和摊还分析理解程序规模增长。
2. 线性结构：表、栈、队列与它们在表达式处理、缓冲、搜索中的用法。
3. 树结构：二叉树、搜索树、堆、并查集，是后续算法课的基础。
4. 图算法：图表示、拓扑排序、最短路，是很多系统与 AI 问题的抽象入口。
5. 工程训练：课程项目要求把理论结构实现成可靠程序，并用测试说明正确性。

## 学习建议

这门课不要只背接口。每学完一种结构，都应该能回答三个问题：它支持哪些操作、这些操作的复杂度是多少、如果输入规模变大哪里会先成为瓶颈。复习时优先手写二叉树遍历、堆操作、并查集路径压缩、图的 BFS/DFS 与最短路流程。
