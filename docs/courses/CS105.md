# Computer System I

计算机系统 I 把程序执行背后的硬件路径打开：从二进制表示、指令集、数据通路到流水线，让“代码为什么这样运行”变成可以推导的结构。它是体系结构、操作系统和编译原理之前的一门地基课。

## 课程主线

1. 数据表示：整数、浮点数、补码、溢出与位级操作。
2. 指令执行：汇编、寻址方式、控制流与函数调用。
3. 数据通路：单周期、多周期与流水线处理器的组成。
4. 性能理解：CPI、流水线冒险、旁路与暂停。
5. 实验与作业：通过 datapath、控制信号和题目推演把抽象结构落到硬件路径。

## 学习建议

系统课的复习重点是“能画出来”。如果一条指令进入 datapath，你应该能追踪每个控制信号、寄存器读写和 ALU 操作。做题时先把信息流画清楚，再算周期和性能指标，会比直接套公式稳定很多。
