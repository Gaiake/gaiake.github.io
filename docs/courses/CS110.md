# Causal Inference

因果推理连接统计、机器学习和人工智能。它关心的问题不是“变量之间是否相关”，而是“如果我们干预某个变量，结果会如何变化”。这门课对理解实验设计、反事实推理、因果发现和大模型可靠性都很重要。

## 课程主线

1. 因果问题建模：处理变量、结果变量、混杂因素与反事实。
2. 潜在结果框架：ATE、ATT、随机实验与可识别性。
3. 观测数据方法：匹配、倾向得分、IPW、回归调整。
4. 因果与机器学习：用因果结构提升泛化、解释和鲁棒性。
5. 因果与大模型：从事实性、推理可靠性到实验评估。

## 学习建议

因果推理最重要的是区分三件事：相关、预测、干预。每做一道题都先写清楚因果图或潜在结果假设，再决定能否识别、用什么估计量、估计量依赖哪些条件。这样能避免把机器学习预测问题误当成因果问题。
