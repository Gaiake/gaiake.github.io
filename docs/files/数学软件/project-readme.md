# Mathematical Software Final Project

This repository implements the final project for the 2025-2026 Mathematical Software course: a reduced patched-conic and numerical-propagation study of a 2026 Earth-Moon assist into a solar-perihelion transfer.

## Quick Start

```bash
make all
```

The command runs the test suite, generates figures and scan data, and compiles `report.tex` into `build/report.pdf`.

If XeLaTeX is not installed, run only:

```bash
make test
make figures
```

## Notes

The assignment PDF emphasizes `CENTER='@10'` for Sun-centered Horizons calls. The helper in `src/horizons.py` always adds the `@` marker to avoid confusing an observatory code with a body center. To perform a live Horizons check:

```bash
python3 -m src.horizons
```

Set `HORIZONS_API_URL` and `HORIZONS_TOKEN` if the course proxy is required.

Rule 9 validation entry. The repository includes a small 2026 JPL Horizons validation cache so this works offline:

```bash
python3 -m src.horizons_validation --output-dir build
```

To refresh the validation cache from live JPL Horizons first:

```bash
python3 -m src.horizons_validation --live --output-dir build
```

Rule 15 real lunar encounter entry:

```bash
python3 -m src.real_lunar_flyby
```

## Optional Extensions

Run the GUI demo separately:

```bash
python3 -m src.interactive_demo
```

The innovation extension can also be run directly:

```bash
python3 -m src.innovation_parallel
python3 -m src.innovation_diagnostics
```

The included model is intentionally transparent and reproducible. It combines a two-body solar transfer estimate with a reduced lunar flyby gain model, then scans launch date, lunar perilune distance, flyby side, and solar perihelion. The report names the approximation limits explicitly.
