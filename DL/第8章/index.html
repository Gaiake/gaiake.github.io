    第八章 表征学习¶

    好的表征使得"语义相似" = "几何接近" —— 从特征工程到自监督表征学习的完整演进

    一、什么是表征 (Representation)¶

    1.1 表征的定义¶

    核心定义

    表征 (Representation) 是对数据含义的编码，是对原始数据的一种映射。

    \[ \text{Raw Data} \xrightarrow{\text{Representation}} \text{Representation Space} \]

    表征的最终目标是将原始数据（图像、文本、音频等）转换为一个低维稠密向量，使得在该向量空间中： - 语义相似的样本 → 几何位置接近（距离小） - 语义不同的样本 → 几何位置远离（距离大）

    1.2 为什需要表征学习？¶

    需求 说明
    降低数据维度 原始数据通常维度极高（如图像的像素数、文本的词表大小），表征将其压缩为低维向量
    捕获数据语义 原始像素/字符层面无法直接体现语义，表征向量将语义编码为几何关系
    提升泛化能力 好的表征可迁移到多个下游任务，无需为每个任务重新设计特征

    二、传统表征提取模式：特征工程 (Feature Engineering)¶

    2.1 文本数据特征¶

    词袋模型 (Bag-of-Words, BoW)

    BoW原理

    统计文档中每个单词出现的频次，构建一个以词表为维度、频次为值的向量。

    • 优点：简单快速，可解释性强
    • 缺点：完全丢失语序信息，"A kills B"与"B kills A"的向量相同

    TF-IDF

    TF-IDF: 词频 × 逆文档频率

    在BoW基础上，引入逆文档频率(IDF)来降低常见词（如"的""是"）的权重，提升关键词的重要性。

    \[ TF-IDF(t, d, D) = tf(t, d) \times idf(t, D) \]
    • TF (Term Frequency)：词 t 在文档 d 中出现的频率
    • IDF (Inverse Document Frequency)：log(总文档数 / 包含词t的文档数)
    • 当一个词在单篇文档中出现频繁、但在整个语料库中罕见时，其TF-IDF值最高
    文档 blue bright can see shining sky sun today
    Doc1 0.301 0 0 0 0 0.151 0 0
    Doc2 0 0.0417 0 0 0 0 0.0417 0.201
    Doc3 0 0.0417 0 0 0 0.100 0.0417 0
    Doc4 0 0.0209 0.100 0.100 0.100 0 0.0417 0

    2.2 图像数据特征¶

    SIFT (Scale-Invariant Feature Transform)

    SIFT提取128维梯度方向描述符，对图像的局部关键点进行描述。 - 通过多尺度空间检测关键点 - 对每个关键点统计周围区域的梯度方向直方图 - 对旋转、缩放具有尺度不变性

    步骤 说明
    Scale-space extrema detection 检测尺度空间中潜在的关键点位置
    Keypoint localization 精确定位并过滤不稳定点
    Orientation assignment 为关键点分配主方向
    Keypoint descriptor 构建128维梯度方向描述符

    HOG (Histogram of Oriented Gradients)

    HOG通过统计图像局部区域的梯度方向直方图来描述物体轮廓。

    1
    Input Image → Gradient Image → Orientation Voting → Local Normalization → Overlapping Blocks

    2.3 特征工程的三大缺陷¶

    特征工程的三大核心缺陷

    1. 需要人工设计特征模式，需要领域经验，设计成本高
    2. SIFT和HOG的设计依赖大量视觉领域的先验知识

    3. 换一个域（如医学影像）又要重新设计特征

    4. 只能表达局部语义，难以捕捉复杂语义，难以建模非线性结构

    5. BoW忽略语序和语法结构

    6. SIFT/HOG仅描述局部纹理和边缘

    7. 泛化能力弱，需要对任务针对性地设计特征

    8. 图像分类的特征≠目标检测的特征
    9. 文本分类的特征≠情感分析的特征

    三、现代范式：表征学习 (Representation Learning)¶

    3.1 核心思想¶

    数据驱动代替人工设计

    不再手工设计特征提取规则，而是用模型来学习表征：

    \[ \text{原始数据}\; x \xrightarrow{\text{Encoder } f} \text{表征向量}\; z = f(x) \]
    范式 监督信号来源 特点
    监督表征学习 人工标注标签 任务针对性强,但标注成本高
    自监督表征学习 数据自身特性 无需标注,泛化性、迁移性强

    3.2 有监督 vs 自监督表征学习¶

    比较维度 有监督表征学习 无监督/自监督表征学习
    核心思想 利用人工标注的标签,引导模型学习与任务相关的表征 从数据本身的结构与分布中,自动发现有意义的表征
    典型方法 交叉熵/回归损失驱动的端到端学习 对比学习、掩码建模、生成式模型......
    优势 任务针对性强,与下游任务直接对齐 数据成本低;泛化性、迁移性强
    局限 标注成本高;容易过拟合特定任务 训练目标未必反应特定任务语义

    四、如何评估表征的好坏？¶

    4.1 Linear Probing（线性探测）¶

    Linear Probing的原理

    在下游任务上，冻结预训练好的Encoder，仅用表征向量 z 和标签 y 来训练一个线性分类器。用线性分类器的效果来评判表征的语义表达能力。

    1
    Encoder (冻结) → 表征向量 z → Linear Classifier (可训练) → 预测标签

    为什么用线性分类器？ - 线性模型能力有限，如果线性分类表现好 → 说明表征本身已经很好地编码了语义信息 - 如果必须用复杂分类器才能表现好 → 说明表征本身质量不够，需要额外非线性变换补救

    4.2 可视化观察聚类效果¶

    对高维表征进行降维可视化（常用PCA、t-SNE算法），观察：

    • 类间分离 (Inter-class Separation)：不同类别的样本在向量空间中是否远远分开
    • 类内紧凑 (Intra-class Compactness)：同类样本是否紧密聚集在一起
    评估维度 好的表征 差的表征
    类间分离 不同类别形成清晰的簇,簇间距离大 各类别混合在一起,边界模糊
    类内紧凑 同类样本聚集成紧密的簇 同类样本分散在各处

    可视化流程

    1
    高维表征 → PCA/t-SNE降维到2D/3D → 按真实标签着色 → 观察聚类结构

    五、Pretext 任务（代理任务）¶

    5.1 什么是 Pretext 任务？¶

    核心思想

    摒弃人工标注，以数据自身属性为"伪标签"（Pseudo Label），通过解决人为设计的代理任务，间接习得数据的语义特征。

    1
2
3
4
    原始图像（未标注数据） → 自动变换（旋转/打乱/灰度化/取patch）
    → 伪标签（角度/排列/相对位置/颜色）
    → 预训练模型（学习视觉表示）
    → 下游任务（分类/检测）

    5.2 旋转预测 (Rotation Prediction)¶

    将一张自然图像随机旋转为 0°、90°、180°、270°，让模型预测旋转角度（4分类问题）。

    模型需要学会的能力： - 识别主体轮廓（如猫的头朝上还是朝下） - 判断部件朝向（如车轮、窗户的方向） - 理解场景重力方向（天空在上、地面在下）

    训练流程¶

    步骤 说明
    Step 1: 定义旋转变换 设定四个角度 \(0^\circ, 90^\circ, 180^\circ, 270^\circ\)，对应标签 \(y \in \{0,1,2,3\}\)
    Step 2: 构建训练样本 对每张图像生成4个旋转版本
    Step 3: 训练网络 Encoder f + 分类器 g（4分类），最小化交叉熵损失
    Step 4: 下游迁移 用训练好的Encoder提取表征，用于下游任务
    \[ \mathcal{L}_{Rotation} = -\sum_{y=0}^{3} y \log g(f(x_y)) \]

    5.3 其他 Pretext 任务¶

    任务 方法 学习目标
    相对位置预测 (Context Prediction) 从同一图像采样两个patch，模型预测第二个patch相对第一个的方向（8分类） 理解物体各部件的位置关系
    拼图游戏 (Jigsaw Puzzle) 将图像分块打乱，模型预测排列方式（从9!=362,880种中选100种） 学习局部空间关系及从局部推断全局结构
    着色 (Colorization) 将彩色图转为灰度图，让模型恢复颜色 关注纹理、材质、区域类别及颜色连续性

    着色的语义特性

    颜色恢复本质上依赖语义理解： - 天空 → 蓝色系 - 植被 → 绿色系 - 皮肤 → 肤色系 模型必须理解"这是什么物体"才能正确着色。

    5.4 不同 Pretext 任务的性能比较¶

    在 ImageNet-1000 分类任务上（冻结表征 + MLP）：

    Method Conv4 Conv5
    ImageNet labels (supervised) 59.7 59.7
    Random 27.1 12.0
    Context Prediction 45.6 30.4
    Colorization 40.7 35.2
    Jigsaw Puzzle 45.3 34.6
    RotNet (Rotation Prediction) 50.0 43.8

    RotNet在Conv5层达到43.8%，显著优于其他Pretext任务，说明==旋转预测能学到更高质量的视觉表征==。

    5.5 Pretext 任务的局限性¶

    两大核心局限

    1. 泛化性有限：模型可能学会"如何解这道题"，却不一定得到对下游任务最有用的通用表示
    2. 旋转预测任务教会模型判断方向，但不一定学会物体类别

    3. 着色任务教会模型预测颜色，但不一定学会物体形态

    4. 可能出现学习捷径 (Shortcut Learning)：

    5. 边缘连续性：模型通过图像边缘的连续性来拼图，而非理解物体结构
    6. 颜色分布：通过统计颜色直方图分布来取巧，而非理解语义
    7. 相机伪影：利用传感器噪声、JPEG压缩痕迹等低级特征

    六、对比学习：从依赖标签到实例判别¶

    6.1 核心思想¶

    从"解题"到"识人"

    Pretext任务教会模型"如何玩游戏"，但我们真正需要模型能 "区分谁是谁"。

    对比学习 (Contrastive Learning)：在特征空间中， - 拉近同类事物（正样本对） - 推远不同类事物（负样本对）

    6.2 监督对比学习 vs 自监督对比学习¶

    方法 正负样本来源 成本
    监督对比学习 人工标注哪些属于同类 / 不同类 ★★★ 成本高
    自监督对比学习 通过数据变换自动构建正负样本对 ★ 免费午餐！

    6.3 SimCLR 框架¶

    SimCLR：最经典的对比学习框架

    对每张图施加两种不同的数据增强，形成一对互为"正样本"的分身。模型的目标就是识别这些分身属于同一母体，并同时排斥 batch 内的所有其他图片。

    惊人成果：自监督特征仅用1%标签微调就能超越AlexNet！

    整体架构

    ↓ Data Augmentation
    ├──→ x_i → Encoder f → h_i → Projector g → z_i →┐

                                                      ↓

    核心组件详解

    6.1 数据增强 (Data Augmentation)¶

    关键发现

    • 数据增强组合对自监督学习质量起决定性作用
    • 单纯的随机裁剪效果不佳（模型作弊）
    • 必须与 "颜色抖动 (Color Distortion)" 结合使用
    增强类型 说明 作用
    Crop and resize 随机裁剪后缩放到统一尺寸 让模型关注不同尺度的内容
    Crop, resize and flip 裁剪 + 水平翻转 增加几何变换多样性
    Color distort (drop) 随机丢弃颜色通道 防止模型靠颜色作弊
    Color distort (jitter) 随机改变亮度/对比度/饱和度/色相 防止模型靠颜色作弊
    Rotate 随机旋转一定角度 增加方向多样性
    Cutout 随机遮挡图像块 迫使模型从剩余部分推断
    Gaussian noise 添加高斯噪声 增加鲁棒性
    Gaussian blur 高斯模糊 关注全局结构而非细节
    Sobel filtering 边缘检测滤波 强调轮廓信息

    6.2 基础编码器 (Base Encoder)¶

    通常采用经典的卷积神经网络（如 ResNet-50），作为模型的"主干"，负责将原始图像转化为高维特征向量 h。

    • ResNet-50 输出 2048 维特征向量
    • 目标：捕捉图像中核心的语义内容

    6.3 投影头 (Projector)¶

    投影头的作用

    Projector 专门负责吸收和过滤掉那些对对比任务有用、但对通用识别没用的冗余信息（颜色、位置），保护前面的编码器能学到更纯净、更本质的语义特征。

    • 结构：Dense → ReLU → Dense
    • 输出：经过投影的表征 z
    • 训练后丢弃 Projector，只保留 Base Encoder 用于下游任务

    6.4 对比损失 (NT-Xent Loss)¶

    NT-Xent (Normalized Temperature-Scaled Cross-Entropy Loss) 损失函数：

    \[ \ell(i,j) = -\log \frac{\exp(s_{i,j})}{\sum_{k=1}^{2N} \mathbb{1}_{[k \neq i]} \exp(s_{i,k})} \]
    \[ L = \frac{1}{2N} \sum_{k=1}^{N} [\ell(2k-1, 2k) + \ell(2k, 2k-1)] \]
    术语 含义
    \(s_{i,j}\) 向量 \(z_i\) 与 \(z_j\) 的余弦相似度
    N batch 大小
    2N 增强后总样本数
    分子 正样本对相似度（越大越好）
    分母 所有样本对相似度总和
    损失最小化 → 正样本对相似度↑，所有负样本对相似度↓

    6.5 SimCLR 性能¶

    Model Parameters (Millions) ImageNet Top-1 (%)
    InstDisc 25 54
    MoCo 25 60
    Rotation 100 55
    SimCLR (2x) 100 74
    SimCLR (4x) 400 76
    Supervised (oracle) - -

    SimCLR(4x) 以 400M 参数实现 76% Top-1 准确率，远超前人方法。

    6.4 MoCo——动量更新编码器¶

    MoCo (Momentum Contrast)

    问题：SimCLR 依赖大 batch size 来提供充足负样本，计算资源门槛高。

    MoCo 的解决方案： 1. 引入一个动态队列存储负样本的特征向量 2. 使用动量更新 (Momentum Update) 的方式更新 Key Encoder

    动量更新公式

    \(\theta_k \leftarrow m\theta_k + (1-m)\theta_q\)

    符号 含义
    \(\theta_k\) Key Encoder（右侧，生成负样本特征）
    \(\theta_q\) Query Encoder（左侧，生成查询特征）
    m 动量系数，通常取 0.999（缓慢更新）

    动量更新的优势

    • Key Encoder 更新极其缓慢，保证负样本特征表示前后一致性
    • 队列可存储大量历史负样本（如 65536 个），无需依赖大 batch
    • SimCLR 发表更晚、消融更全面，发现算力充足时直接开大 batch 也可以

    6.5 对比学习家族概览¶

    方法 核心特性 负样本
    SimCLR 对称架构,InfoNCE损失,大batch batch内所有其他样本
    MoCo 动量更新Encoder,队列存储负样本 队列中的历史特征
    BYOL 无负样本,预测头+MSE损失 无需负样本
    SwAV 聚类+对比,交换预测分配 聚类原型
    SimSiam 极简架构,stop-gradient防坍塌 无需负样本
    SimTriplet triplet变体,适合patch匹配 三元组样本

    七、单词的表征学习¶

    7.1 One-hot 编码的局限¶

    传统 NLP 的 One-hot 表征

    在传统 NLP 中，每个单词被表示为 One-hot 向量：

    火车 = [0, 0, 0, 0, 0, 1, 0, 0] 高铁 = [0, 0, 0, 1, 0, 0, 0, 0]

    两大缺陷： 1. 维度灾难：维度 = 词表大小（如 500,000+），极度稀疏 2. 语义正交："火车"与"高铁"的内积为 0（正交），完全无法体现语义相似度

    当我们搜索"去杭州的火车"时，也隐含了想搜索"去杭州的高铁"， 但 One-hot 向量中两者是正交的！

    解决方案：通过表征学习得到能够包含词汇语义的低维稠密向量。

    7.2 Word2Vec 算法¶

    Word2Vec (Mikolov et al. 2013, ICLR Workshop)

    核心思想¶

    分布式假设 (Distributional Hypothesis)

    "一个词的含义是由经常出现在它附近的词语决定的。"

    ...government debt problems turning into banking crises as happened in 2009... ...saying that Europe needs unified banking regulation to replace the hodgepodge.. ...India has just given its banking system a shot in the arm...

    统计语言模型¶

    最大化文本语料的概率。

    假设句子 \(W = (w_1, w_2, ..., w_T)\)，其联合概率为：

    \(p(W) = p(w_1)p(w_2|w_1)p(w_3|w_1,w_2)\dots p(w_T|w_1,\dots,w_{T-1})\)

    词表大小为 N，共有 \(N^T\) 种可能性！直接计算不可行。

    算法五步¶

    1. 前提：有一个大的语料库
    2. 初始化：词表中每个单词由一个向量表示
    3. 定义：对于文本中每个位置 t，有中心词 c 和上下文 o
    4. 计算：通过 c 和 o 的向量相似度，计算条件概率
    5. 优化：调整单词向量，最大化语料概率

    两种变体¶

    Skip-gram vs CBOW

    变体 输入 → 输出 特点
    Skip-gram 中心词 → 上下文 适合低频词，精度高
    CBOW 上下文 → 中心词 训练速度快

    下面以 Skip-gram 为例详细介绍：

    Skip-gram 目标函数¶

    \(Likelihood L(\theta) = \prod_{t=1}^{T} \prod_{-m \leq j \leq m \\ j \neq 0} P(w_{t+j} | w_t; \theta)\)

    \(J(\theta) = -\frac{1}{T} \log L(\theta) = -\frac{1}{T} \sum_{t=1}^{T} \sum_{-m \leq j \leq m \\ j \neq 0} \log P(w_{t+j} | w_t; \theta)\)

    条件概率计算¶

    每个单词用两个向量表示：中心词向量 \(v_w\) 和上下文向量 \(u_w\)

    \(P(o|c) = \frac{\exp(u_o^T v_c)}{\sum_{w \in V} \exp(u_w^T v_c)}\)

    中心词向量和上下文向量分开更加灵活，有利于模型优化

    优化：负采样 (Negative Sampling)¶

    问题

    对每个上下文 o，需要计算其与词表 V 中所有单词的相似度，复杂度极高！

    解决方案：负采样

    将多分类转化为多个二分类。 每对正样本只计算与 k 个随机负样本的相似度（k 一般取 5~20）。

    \(J_t(\theta) = \log \sigma(u_o^T v_c) + \sum_{i=1}^{k} \mathbb{E}_{j \sim P(w)} \left[ \log \sigma(-u_j^T v_c) \right]\)

    术语 含义
    \(\sigma\) Sigmoid 函数
    \(u_o^T v_c\) 真实上下文的相似度（要最大化）
    \(-u_j^T v_c\) 负样本的相似度（要最小化）
    \(P(w)\) 采样分布，\(\propto U(w)^{0.75}\)（降低高频词被采样概率）

    优化：层次 Softmax (Hierarchical Softmax)¶

    另一个解决方案：构建Huffman 树，每个叶子节点对应一个单词，非叶子节点为二分类器。

    • 多分类 → 多个二分类
    • 高词频 → 更短路径 → 计算更快
    • Softmax 转化为从根节点到叶子节点的二分类概率连乘

    7.3 GloVe 算法¶

    GloVe (Pennington et al. 2014, EMNLP)

    从局部上下文到全局统计¶

    核心发现

    单词共现矩阵 (Co-occurrence Matrix) 蕴含了相似度语义。

    \(P(x \mid \text{ice})\) \(P(x \mid \text{steam})\) 比值 含义
    large (solid) small (solid) >>1 solid 与 ice 更相关
    small (gas) large (gas) <<1 gas 与 steam 更相关
    large (water) large (water) ~1 water 与两者都相关
    small (fashion) small (fashion) ~1 fashion 与两者都不相关

    目标函数¶

    \(\sum_{i,j} f(X_{ij}) \left(v_i^\top v_j + b_i + b_j - \log X_{ij}\right)^2\)

    符号 含义
    X 共现矩阵
    i 中心词
    j 上下文词
    v 可学习的单词向量
    \(\log\) 缩小频率差距
    b 偏置项，提高拟合灵活性
    f 权重参数，平衡高频词和低频词的训练比重

    表征的线性结构¶

    GloVe 学习到的词向量展现出惊人的线性语义结构

    \(woman - man + king \approx queen\)

    八、文本数据的自监督学习¶

    8.1 背景：RNN/LSTM 与 Transformer¶

    RNN (循环神经网络)

    针对序列数据的上下文连续建模。当前时刻输出同时取决于当前输入和前一时刻的隐藏状态。

    LSTM (长短期记忆网络)

    解决 RNN 梯度消失/爆炸问题。引入遗忘门、输入门、输出门，有选择地保留关键信息、丢弃无关内容。

    Transformer

    Transformer 的革命性突破

    • 突破并行瓶颈：Self-Attention 允许序列中所有位置同时计算
    • 解决长程依赖：任意两个词的距离都被视为 1
    • 开启 Scaling Law：利用海量数据训练超大参数模型成为可能

    8.2 ELMo (Embeddings from Language Models)¶

    Word2Vec 的局限

    Word2Vec 为每个词赋予唯一向量，无法解决一词多义问题（如 "bank" 可以是银行、河岸）。 下游任务依赖大量人工标注。

    ELMo 的核心方案

    训练两个独立方向的 LSTM（左→右 和 右→左），将同一词在两组 LSTM 顶层产生的隐藏状态与原始词向量拼接，形成随上下文动态变化的深层语境化表征。

    ELMo 的局限

    ELMo 的局限

    由于两个 LSTM 独立训练、参数不共享，上下文信息仅在最后阶段进行浅层拼接，无法实现词语间的深层双向交互与融合。

    8.3 BERT (Bidirectional Encoder Representations from Transformers)¶

    BERT 旨在通过自注意力使每一层都同时编码两侧上下文，实现更深层的双向理解。

    核心机制：去噪自编码 (Masked Language Model, MLM)

    随机 15% 掩码，利用上下文重建（完形填空！）

    Masking 策略

    随机选择输入序列中 15% 的 token：

    概率 处理方式 目的
    80% (选中 token 中的) 替换为 [MASK] 主要训练信号
    10% (选中 token 中的) 替换为随机 token 防止模型只学 mask
    10% (选中 token 中的) 保持不变 保持与微调阶段表征对齐

    BERT 优化目标

    \(\mathcal{L}_{MLM} = \mathbb{E}_{x \in \mathcal{D}} \sum_{i \in \mathcal{M}} -\log P(x_i \mid x_{\backslash \mathcal{M}})\)

    其中 \(\mathcal{M}\) 为被遮挡位置的索引集合，x_{\(\backslash \mathcal{M}\)} 为其余可见 token。

    BERT 性能

    System MNLI QQP QNLI SST-2 CoLA Average
    Pre-OpenAI SOTA 80.6/80.1 66.1 82.3 93.2 35.0 74.0
    BiLSTM+ELMo+Attn 76.4/76.1 64.8 79.8 90.4 36.0 71.0
    OpenAI GPT 82.1/81.4 70.3 87.4 91.3 45.4 75.1
    BERT_BASE 84.6/83.4 71.2 90.5 93.5 52.1 79.6
    BERT_LARGE 86.7/85.9 72.1 92.7 94.9 60.5 82.1

    BERT 的局限

    BERT 的局限

    1. 训练规模保守，模型潜力尚未激发——Scaling Law
    2. 引入的句级 NSP (Next Sentence Prediction) 辅助任务以及输入格式可能分散核心掩码学习——消融实验研究

    8.4 RoBERTa (Robustly Optimized BERT Approach)¶

    Scaling Law 验证

    保持 BERT 架构完全不变，仅改变训练规模：

    配置 数据 步数 SQuAD v1.1/v2.0 MNLI-m SST-2
    BERT (Books+Wiki) 16GB 100K 93.6/87.3 89.0 95.3
    + additional data 160GB 100K 94.0/87.7 89.3 95.6
    + pretrain longer 160GB 300K 94.4/88.7 90.0 96.1
    + pretrain even longer 160GB 500K 94.6/89.4 90.2 96.4

    结论：训练充分性比架构创新更能决定预训练模型上限。

    消融探究

    RoBERTa 移除 NSP 辅助任务，改变输入格式，进行了消融实验：

    Model SQuAD 1.½.0 MNLI-m SST-2 RACE
    (With NSP) SEGMENT-PAIR 90.4/78.7 84.0 92.9 64.2
    (Without NSP) FULL-SENTENCES 90.4/79.1 84.7 92.5 64.8
    (Without NSP) DOC-SENTENCES 90.6/79.7 84.7 92.7 65.6

    核心启示

    预训练任务的设计应聚焦于核心表征学习目标，冗余的辅助任务不仅非必需，还可能干扰模型对深层语义结构的捕捉。

    8.5 NTP 回归——从理解到生成¶

    路线 架构 代表
    理解路线 BERT 双向去噪 BERT, RoBERTa
    生成路线 NTP 单向预测 GPT 系列

    NTP (Next Token Prediction)

    将序列建模为条件概率的连乘积：

    \(P(x_1, x_2, \dots, x_T) = \prod_{t=1}^{T} P(x_t \mid x_1, \dots, x_{t-1})\)

    模型只能依赖左侧已生成内容来推断后续 token，这种单向约束使其在生成流畅文本上具有先天优势。

    8.6 GPT 系列¶

    从 GPT-1 到 GPT-3

    OpenAI 坚持 decoder-only 自回归架构，通过参数与数据规模的指数级扩展，证明规模化本身足以驱动性能从"需要微调"提升至 "上下文即学习 (In-Context Learning)"。

    Model Parameters 关键特性
    GPT-1 117M 首次证明 decoder-only 在 NLU 上的有效性
    GPT-2 1.5B 展示 zero-shot 能力
    GPT-3 175B 上下文即学习，无需微调

    ChatGPT：RLHF 对齐

    在 GPT-3.5 基础上引入 RLHF

    RLHF (Reinforcement Learning from Human Feedback) 三阶段：

    1. SFT (Supervised Fine-Tuning)：用高质量人工标注对话数据微调预训练模型
    2. RM (Reward Model)：对人类排序的模型输出进行训练，学习预测人类偏好
    3. PPO (Proximal Policy Optimization)：最大化 RM 评分，约束与 SFT 模型的偏离

    结果：将模型输出与人类偏好对齐，标志着大模型产品化的关键转折。

    8.7 Chinchilla¶

    动机

    基于 Scaling Law，GPT-3 后大模型普遍进行盲目扩参。难道这是性能提升的唯一解法吗？

    核心发现

    在相同计算预算下，主流大模型严重训练不足。缩小模型规模并等比例增加数据量，可获得更优的下游性能。

    模型对比

    Model Parameters Training Tokens
    GPT-3 175B 300B
    Gopher 280B 300B
    MT-NLG 530B 530B 270B
    Chinchilla 70B 1.4 Trillion

    Chinchilla 以 70B 参数、1.4T token，在广泛下游任务上全面超越 280B 的 Gopher 和 530B 的 MT-NLG！

    最优配比

    Chinchilla 对 400+ 模型（70M~16B）进行训练曲线拟合，发现：

    • 模型规模与数据规模应随计算预算近似等比例扩展
    • 约 20:1 的 token-参数比成为计算最优训练的核心约束
    • 推翻了此前 Kaplan et al. (2020) 结论"扩参远快于扩数据"
    Approach Coeff. \(a\) (\(N_{opt} \propto C^a\)) Coeff. \(b\) (\(D_{opt} \propto C^b\))
    Min over curves 0.50 0.50
    IsoFLOP profiles 0.49 0.51
    Parametric modelling 0.46 0.54
    Kaplan et al. (2020) 0.73 0.27

    启示

    Chinchilla 的工程优势与伦理挑战

    工程优势： - 更优的模型并不一定需要更大的部署开销 - 显著降低推理与微调的计算开销

    伦理挑战： - 更大规模的数据将不可避免地包含有毒信息、社会偏见与个人信息 - 数据集的质量控制、训练-测试重叠检测以及伦理审查变得至关重要

    预训练的竞争指标应该从 参数量 转变为 单位计算量的性能效率。

    8.8 图像掩码重建 (Masked Image Modeling, MIM)¶

    MAE (Masked Autoencoder)

    核心思想：通过残缺理解整体

    • 遮挡图像 75% 的区域
    • 迫使模型利用仅存的 25% 可见部分 去重建全局内容
    • 跳出局部纹理局限，真正习得物体结构与语义关联

    非对称高效架构： - 重型 Encoder：仅处理 25% 的可见图块 → 学习强表征 - 轻型 Decoder：负责像素重建 → 解耦学习与重建 - 训练速度提升 3-5 倍

    SimMIM

    SimMIM

    直接对图像块进行随机掩码，并通过轻量预测头回归原始像素值。

    • 无需离散化或复杂结构
    • 大幅降低计算成本
    • 能适配 ViT、Swin 等多种骨干网络

    九、自监督表征学习总结¶

    9.1 核心思想¶

    自监督学习的核心

    不依赖人工标注，通过从数据内部挖掘结构来自动生成监督信号，从而训练模型提取出能抓住数据本质的通用特征表示。

    9.2 演进路线¶

    1
    特征工程 → Pretext任务 → 对比学习 → 掩码重建
    时期 核心思路 代表方法 特点
    早期 (2015-2018) 设计手工 Pretext 任务 Rotation, Jigsaw, Colorization 教会模型"解题"
    爆发期 (2019-2020) 对比学习,实例判别 SimCLR, MoCo, BYOL 从根本上学习区分万物
    融合期 (2021-2022) 掩码图像建模(MIM) MAE, BEiT, SimMIM 视觉与 NLP 架构大统一
    现代 (2023-现在) 多模态表征 LLM, VLM, CLIP 通向通用人工智能(AGI)

    9.3 图像 vs 文本自监督学习的区别¶

    维度 语言 (NLP) 图像 (CV)
    数据性质 离散 Token，天然具备序列、句法、上下文依赖 连续像素信号，局部像素相似性不代表语义
    自监督方式 直接掩码预测 → 学习深层语义 需构造代理任务或对比学习间接学习
    文本独特优势 离散符号 → 天然适合 Token 预测 连续信号 → 语义鸿沟大

    9.4 自监督学习的广泛应用¶

    领域 应用
    计算机视觉 分类、检测、分割、深度估计
    自然语言处理 理解、生成、翻译、问答
    多模态 图文匹配、视觉问答、图文生成
    大模型 自监督表征学习是大模型 (LLM, VLM) 的核心引擎

    回顾开篇

    好的表征使得"语义相似" = "几何接近"

    从手工特征工程到自动表征学习，从 Pretext 任务到对比学习，从 Word2Vec 到 BERT/GPT，自监督表征学习已成为现代深度学习的基石，驱动着通用人工智能的持续演进。
