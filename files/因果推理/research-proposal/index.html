    CVA-Debate：面向中文常识陷阱的多智能体因果变量审计研究方案¶

    1. 研究题目¶

    中文题目：多智能体因果变量审计：面向中文常识陷阱中虚假相关推理的边界分析

    英文题目：CVA-Debate: Causal Variable Audit for Multi-Agent Reasoning on Chinese Commonsense Causal Traps

    2. 一句话概括¶

    本研究提出一种 Causal Variable Audit Debate, CVA-Debate 框架，将多智能体辩论从自由形式的“互相质疑”改造成结构化的“因果变量审计”，显式区分核心因果变量、虚假相关变量和语境反转变量，并用中文常识陷阱题分析该框架何时能纠错、何时会过度纠错。

    3. 研究背景与问题¶

    大语言模型在常识推理和因果判断中容易依赖表面共现关系。例如：

    • “程序员 + 久坐”容易诱导模型回答颈椎病或腰椎病，但“剧烈胸痛、冷汗、濒死感”才是急性心肌梗死的关键线索。
    • “负面词汇 + 产品评价”容易诱导模型判定差评，但“把地毯上的灰尘和猫毛清理干净”才是吸尘器评价的核心事实。
    • “黑头套 + 现金袋 + 银行警报”容易诱导模型判定抢劫，但“咔！这条拍得太完美了，收工！”是语境反转线索，指向电影拍摄。

    已有多智能体辩论方法表明，多个模型实例之间的讨论可以提升事实性和推理能力。但在当前项目实验中，普通因果辩论并未稳定提升准确率，甚至出现了明显的 over-correction：初始回答本来正确，经过因果审查后反而被推翻为错误答案。

    因此，本研究不再把目标设定为“证明多智能体一定提升因果推理”，而是聚焦一个更具体、更可验证的问题：

    多智能体反事实辩论在中文常识因果陷阱中为什么有时有效、有时反噬？其关键瓶颈是否来自因果变量识别错误？

    4. 核心研究假设¶

    本研究提出以下假设：

    H1：普通多智能体辩论的效果不稳定，主要原因是批判 Agent 无法可靠区分核心线索与干扰线索。

    H2：将批判过程改造为结构化因果变量审计，可以降低将关键语境线索误删为噪声的概率。

    H3：在中文常识陷阱题中，最终准确率并不是唯一重要指标；过度纠错率能够更好揭示多智能体因果推理的失败机制。

    5. 创新点¶

    5.1 从自由辩论到因果变量审计¶

    传统多智能体辩论通常让多个 Agent 分别生成答案、互相批判、最终投票或裁决。这类方法关注“哪个回答更合理”，但没有强制模型说明答案应当对哪些变量敏感、对哪些变量不敏感。

    CVA-Debate 的核心创新是将 Agent B 改造成 Causal Variable Auditor，要求它显式标注：

    • Y, Target Outcome：题目要求判断的结果。
    • X, Core Causal Variable：改变后答案必须随之改变的核心变量。
    • Z, Spurious Variable：看似相关但不应决定答案的表面变量。
    • C, Contextual Reversal Variable：看似是补充背景，实际会反转表面情境的关键语境变量。
    • MSE, Minimal Sufficient Evidence：回答问题所需的最小充分证据集合。

    其中 语境反转变量 C 是本研究针对现有实验失败模式提出的关键补充。没有 C 这一类，模型很容易把“咔！收工”“然而其实”“蛋糕蜡烛”等真正决定答案的语境线索误判为噪声。

    5.2 引入过度纠错率作为诊断指标¶

    多数已有工作只报告最终准确率。但多智能体辩论存在一种特殊失败模式：

    初始答案正确，经过辩论或反思后反而变错。

    本研究将其定义为 Over-Correction，并引入过度纠错率：

    1
    Over-Correction Rate = 初始正确但最终错误的题目数 / 初始正确的题目数

    该指标用于衡量因果批判 Agent 是否过度怀疑正确线索、错误剥离关键证据。

    5.3 构建中文常识因果陷阱诊断集¶

    本研究基于现有 final_20_traps.csv 和相关生成脚本，构建一个小型中文诊断集 Chinese Causal Trap Set。每道题不仅有标准答案，还标注陷阱类型、核心变量、虚假相关变量和语境反转变量。

    该数据集面向自然语言常识因果判断，不追求大规模，而追求可解释、可分类、可用于错误机制分析。

    7. 数据集设计¶

    7.1 数据来源¶

    自创包含20条数据的中文陷阱题文件作为基础

    7.2 数据字段¶

    建议整理成 cva_trap_dataset.csv，字段如下：

    字段 含义 示例
    id 题目编号 001
    question 问题文本 特警拿出插满蜡烛的蛋糕
    ground_truth 标准答案 庆祝生日
    trap_type 陷阱类型 语境反转
    core_variable_x 核心因果变量 蛋糕、蜡烛、小女孩、庆祝行为
    spurious_variable_z 虚假相关变量 防弹衣、战术盾牌、踹门
    reversal_variable_c 语境反转变量 从盾牌后拿出生日蛋糕
    expected_failure 预期模型错误 判定为执行任务

    7.3 陷阱类型¶

    本研究将题目分成四类：

    类型 定义 例子
    虚假相关陷阱 表面身份或统计共现诱导错误 程序员胸痛、纹身犯人
    情绪词误导 情绪词与真实评价方向冲突 吸尘器“暴力吞噬灰尘”
    语境反转陷阱 后文语境反转前文表面事件 “咔！收工”、特警拿蛋糕
    硬因果规则 依赖物理、医学、生理等稳定规则 月球真空不能传声、氰化钾

    9. 核心评估体系设计和数据分析¶

    为了消除单次测试的随机性，我们在包含20道极具诱导性的中文常识陷阱子集上，对普通“自由辩论（FREE）”和“因果变量审计（CVA）”分别进行了 3 次独立运行，并定义了四种认知转换状态和三大进阶指标：

    9.1 状态转移定义¶

    • 00（未纠错）：初始错误，辩论后依然错误。（顽固型认知偏差）
    • 01（成功纠错）：初始错误，辩论后更正为对。（有效批判）
    • 10（过度纠错）：初始正确，辩论后反而改错。（自由辩论带来的主要损伤）
    • 11（正确保持）：初始正确，辩论后坚守正确。（辩论框架的抗干扰防御力）

    9.2 三大进阶诊断指标¶

    • 成功纠错率 (SCR, Successful Correction Rate)：01 / (00+01)，衡量“把错改对”的治愈力。
    • 过度纠错率 (OCR, Over-Correction Rate)：10 / (10+11)，衡量“把对改错”的误杀率（越低越好）。
    • 辩论净收益 (NDB, Net Debate Benefit)：01数量 - 10数量，衡量引入多智能体到底是帮忙还是添乱。

    9.3 总体量化数据分析¶

    基于 sum.csv 的3次运行汇总，整体数据对比如下：

    评估维度 Free Debate (自由辩论) CVA-Debate (因果审计，Ours) 性能对比分析
    初始正确总数 31 题 36 题 起点相近（采用相同底座模型产生初始直觉）
    最终正确总数 24 题 34 题 CVA挽救了性能，FREE导致了断崖式下跌
    成功纠错率 (SCR) 20.7% (6 / 29) 33.3% (8 / 24) CVA 对初始错误的修复能力提升了约 12%
    过度纠错率 (OCR) 41.9% (13 / 31) 27.8% (10 / 36) [关键突破] CVA的大幅拦截了过度反思导致的误杀
    辩论净收益 (NDB) -7 (严重倒退) -2 (趋于稳定) 自由辩论在陷阱题上彻底破产，因果审计实现了强效止血

    量化结论与 H1/H2 假设验证：¶

    数据完美印证了研究方案中的 H1 和 H2。 普通自由辩论的 OCR 高达惊人的 41.9%，这意味着只要模型一开始答对，有近一半的概率会被自由辩论的队友“忽悠”成错的。 而 CVA 通过要求输出 \(X, Z, C, MSE\) 变量，成功把过度纠错率压低了 14 个百分点（降至 27.8%）。虽然面对魔鬼陷阱集未能取得正数绝对收益，但其“防御墙”的提升是极其显著的。

    9.4 定性案例与因果机制诊断¶

    为什么 CVA 起作用？我们在明细数据中通过状态跟踪，得出以下行为机制拆解：

    9.4.1 为什么 CVA 能“正确保持 (11)”？（强力拦截虚假相关 Z）¶

    • 表现与案例：在题11（太空失重舱内的重型铁砧）和题12（被掏空装入iPhone的古董电话）中，自由辩论由于过度关注“铁砧重达千斤”或“电话机布满生锈铜绿”这些外在文本（Z变量），容易在辩论后倒退修改答案。
    • CVA 机制：CVA 强制 Agent B 罗列最小充分证据集 (MSE)。当模型捕捉到真正的物理隔离事实 \(X\)（如“处于失重舱”、“内部是联网的iPhone”）时，逻辑锚点形成。Agent C 的裁决拥有了不受表面形容词干扰的依据，从而成功触发了 11（正确防守） 状态。

    9.4.2 CVA 是如何“成功纠错 (01)”的？（语境反转变量 C 的捕捉）¶

    • 表现与案例：题3（戴头套进银行）。
    • CVA 机制：初始 Agent A 看到“头套、现金、警车”会本能输出“抢劫”。而在 CVA 流水线中，Agent B 的核心任务之一是需单独检索语境反转变量 C。当它提取到“导演喊咔，收工”这条隐藏指令后，Agent C 会根据规则推翻原本构建的 \(Z \rightarrow Y\) 关联，明确这实质是“拍电影”从而修正答案（00 转化为 01）。

    9.4.3 为什么依然存在“过度纠错 (10)”？（深层关联的发散反噬）¶

    • 表现与案例：题2（播音员在沙滩配音）和 题8（发高烧的天才交白卷）。
    • CVA 机制：这暴露了大模型在处理 CVA 时的另一个极端。例如题2，直觉（在沙滩感觉热）其实是对的。但 CVA 强迫模型去寻找可能的反转变量 C，模型有时会“过度解读”，认为“她在念零下四十度的稿子”是颠覆感受的线索，从而推导成“代入角色所以感觉冷”。这是大模型语义表征过热导致的系统级过度联想。

    9.4.4 为什么有些题目“顽固不化 (00)”？（System 1 词汇劫持）¶

    • 表现与案例：题5（形容吸尘器贪婪、暴力吞噬灰尘的好评）。
    • 分析：这种题在 3 次实验的两条线上全军覆没（全部 00）。因为这不是经典物理/逻辑因果图能解决的。题目使用了强烈的“极性反转修辞手法”，大模型底层的 Attention 机制被高浓度的负面词汇（暴力、糟糕、贪婪）死死劫持。因果审计虽然有框架，但审计员提取出的 \(X\) 由于语义偏见早就错了，导致整个审计报告失效。

    9.5 最终研究结论探讨¶

    1. 自由辩论不是银弹，而是陷阱放大器：在充斥虚假相关、语境诱导的中文常识测试中，自由的多智能体互相审阅不仅无益，反而会通过联想发散造成高达 41.9% 的“对改错（识别崩溃）”。
    2. 结构化因果审计（CVA）是必要的前置约束：通过 Pearl 式的因果变量隔离（尤其是明确 \(X\) 与 \(C\)），CVA 有效降低了辩论体系的“致噪率”，使正确保护率（保持结果一致性）显著提升。
    3. 面向反事实的数据集评估必须引入 OCR 指标：传统的 Accuracy 仅仅看黑盒最终结果。本报告通过引入状态转移概率（SCR vs OCR），证明了多智能体提升能力的第一步，首先是建立一个不受表面文本概率绑架的逻辑锚点。CVA 的价值正是在于其卓越的干扰防御能力。

    10. 论文结构¶

    10.1 Introduction¶

    写作要点：

    • LLM 容易受虚假相关影响。

    • 初步实验显示，自由形式因果辩论并不稳定，会产生过度纠错。
    • 本文提出 CVA-Debate，将辩论过程转化为结构化变量审计。

    12. 最终定位¶

    本研究的最终定位是：

    在现有多智能体辩论与 LLM 因果推理工作的交叉处，提出一种面向中文自然语言常识陷阱的结构化因果变量审计方法。该方法不声称解决严格因果推断问题，而是研究 LLM 在自然语言因果判断中如何受到虚假相关、语境反转和注意力劫持影响，并通过 correction 与 over-correction 两类指标揭示多智能体协同推理的有效边界。
